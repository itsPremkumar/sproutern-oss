## 🔢 1. Number System

### Divisibility Rules

| Divisor | Rule                                                 | Example                |
| ------- | ---------------------------------------------------- | ---------------------- |
| **2**   | Last digit even                                      | 124 ✓                  |
| **3**   | Sum of digits divisible by 3                         | 123 → 1+2+3=6 ✓        |
| **4**   | Last 2 digits divisible by 4                         | 1324 → 24÷4 ✓          |
| **5**   | Last digit 0 or 5                                    | 125 ✓                  |
| **6**   | Divisible by both 2 and 3                            | 126 ✓                  |
| **8**   | Last 3 digits divisible by 8                         | 1256 → 256÷8 ✓         |
| **9**   | Sum of digits divisible by 9                         | 729 → 7+2+9=18 ✓       |
| **11**  | (Sum of odd digits) - (Sum of even digits) = 0 or 11 | 1364 → (1+6)-(3+4)=0 ✓ |

### HCF & LCM

**HCF (Highest Common Factor):**

- HCF × LCM = Product of two numbers
- HCF of fractions = HCF of numerators / LCM of denominators

**LCM (Least Common Multiple):**

- LCM of fractions = LCM of numerators / HCF of denominators

**Shortcut for 2 numbers:**

```
HCF × LCM = a × b
```

### Important Formulas

**Sum of first n natural numbers:**

```
S = n(n+1)/2
```

**Sum of squares of first n natural numbers:**

```
S = n(n+1)(2n+1)/6
```

**Sum of cubes of first n natural numbers:**

```
S = [n(n+1)/2]²
```

**Sum of first n odd numbers:**

```
S = n²
```

**Sum of first n even numbers:**

```
S = n(n+1)
```

## 📊 2. Percentage

### Basic Formulas

**Percentage:**

```
Percentage = (Part/Whole) × 100
```

**Percentage Change:**

```
% Change = [(New - Old)/Old] × 100
```

### Fraction-Percentage Conversion Table

| Fraction | Percentage | Fraction | Percentage |
| -------- | ---------- | -------- | ---------- |
| 1/2      | 50%        | 1/8      | 12.5%      |
| 1/3      | 33.33%     | 1/9      | 11.11%     |
| 1/4      | 25%        | 1/10     | 10%        |
| 1/5      | 20%        | 1/11     | 9.09%      |
| 1/6      | 16.67%     | 1/12     | 8.33%      |
| 1/7      | 14.28%     | 1/15     | 6.67%      |

### Successive Percentage Change

If price changes by a% then b%:

```
Net change = a + b + (ab/100)
```

**Example:** 20% increase then 10% decrease

```
Net = 20 + (-10) + (20×-10)/100 = 20 - 10 - 2 = 8% increase
```

### Population Problems

**After n years:**

```
P × (1 + R/100)^n
```

**Before n years:**

```
P / (1 + R/100)^n
```

## 💰 3. Profit & Loss

### Basic Formulas

| Formula                | Expression         |
| ---------------------- | ------------------ |
| Profit                 | SP - CP            |
| Loss                   | CP - SP            |
| Profit %               | (Profit/CP) × 100  |
| Loss %                 | (Loss/CP) × 100    |
| SP when profit         | CP × (100 + P)/100 |
| SP when loss           | CP × (100 - L)/100 |
| CP from SP and Profit% | SP × 100/(100 + P) |
| CP from SP and Loss%   | SP × 100/(100 - L) |

### Marked Price & Discount

```
Selling Price = Marked Price × (100 - Discount%)/100
```

**Two successive discounts of a% and b%:**

```
Equivalent discount = a + b - (ab/100)
```

### Important Shortcuts

**If CP of x items = SP of y items:**

```
Profit % = [(x-y)/y] × 100
```

**Selling at same price with profit a% and loss a%:**

```
Net result = Loss of (a²/100)%
```

## 🏦 4. Simple & Compound Interest

### Simple Interest

```
SI = (P × R × T) / 100

Where:
P = Principal
R = Rate per annum
T = Time in years
```

**Amount = P + SI = P(1 + RT/100)**

### Compound Interest

```
A = P(1 + R/100)^n

CI = A - P = P[(1 + R/100)^n - 1]
```

**Half-yearly compounding:**

```
A = P(1 + R/200)^(2n)
```

**Quarterly compounding:**

```
A = P(1 + R/400)^(4n)
```

### Shortcut for 2-3 years

**CI for 2 years:**

```
CI = SI + SI × R / 100
```

**Difference between CI and SI for 2 years:**

```
Diff = P × (R/100)²
```

**Difference between CI and SI for 3 years:**

```
Diff = P × (R/100)² × (3 + R/100)
```

## ⚖️ 5. Ratio & Proportion

### Basic Concepts

**Ratio:** a:b means a/b

**Proportion:** a:b :: c:d means a/b = c/d

**Product of extremes = Product of means:**

```
a × d = b × c
```

### Important Formulas

**If a:b = c:d, then:**

- Invertendo: b:a = d:c
- Alternendo: a:c = b:d
- Componendo: (a+b):b = (c+d):d
- Dividendo: (a-b):b = (c-d):d

### Dividing in Ratio

**Dividing amount A in ratio m:n:**

```
First part = A × m/(m+n)
Second part = A × n/(m+n)
```

**Example:** Divide ₹500 in ratio 2:3

- First = 500 × 2/5 = ₹200
- Second = 500 × 3/5 = ₹300

## ⏱️ 6. Time & Work

### Basic Concept

If A can do work in n days:

```
A's 1 day work = 1/n
```

### Combined Work

If A does in 'a' days, B does in 'b' days:

```
Together = ab/(a+b) days
```

**For three people (a, b, c days):**

```
Together = abc/(ab + bc + ca) days
```

### Efficiency Ratio

If A is x times efficient as B:

```
Time ratio = B:A = x:1
Work ratio = A:B = x:1
```

### Work & Wages

```
Wages ∝ Work done ∝ Efficiency
```

If wages are distributed in ratio of work done.

### Men-Days Concept

```
M₁ × D₁ × H₁ / W₁ = M₂ × D₂ × H₂ / W₂

Where:
M = Number of men
D = Days
H = Hours per day
W = Amount of work
```

### Pipes & Cisterns

**Inlet fills in 'a' hours, Outlet empties in 'b' hours:**

```
Together = ab/(b-a) hours (if b > a, it fills)
Together = ab/(a-b) hours (if a > b, it empties)
```

## 🚗 7. Time, Speed & Distance

### Basic Formulas

```
Speed = Distance / Time
Distance = Speed × Time
Time = Distance / Speed
```

### Unit Conversions

```
km/hr to m/s: Multiply by 5/18
m/s to km/hr: Multiply by 18/5
```

### Average Speed

**For same distance at speeds a and b:**

```
Average Speed = 2ab/(a+b)
```

**For three equal distances at speeds a, b, c:**

```
Average Speed = 3abc/(ab + bc + ca)
```

### Relative Speed

**Same direction:**

```
Relative Speed = |a - b|
```

**Opposite direction:**

```
Relative Speed = a + b
```

### Trains

**Time to cross a pole/person:**

```
Time = Length of train / Speed
```

**Time to cross a platform:**

```
Time = (Length of train + Length of platform) / Speed
```

**Two trains crossing each other:**

```
Time = (L₁ + L₂) / Relative Speed
```

### Boats & Streams

```
Upstream speed = Boat - Stream
Downstream speed = Boat + Stream

Speed of boat in still water = (Downstream + Upstream) / 2
Speed of stream = (Downstream - Upstream) / 2
```

## 📈 8. Averages

### Basic Formula

```
Average = Sum of observations / Number of observations
```

### Weighted Average

```
Weighted Avg = (w₁x₁ + w₂x₂ + ... + wₙxₙ) / (w₁ + w₂ + ... + wₙ)
```

### Change in Average

**When a new value is added:**

```
New Average = Old Average + (New Value - Old Average)/(n+1)
```

**When a value is replaced:**

```
New Average = Old Average + (New Value - Old Value)/n
```

### Age Problems Shortcut

- Average age increases by 1 every year
- If a person joins/leaves, use the difference method

## 🧪 9. Mixtures & Alligation

### Alligation Rule

When mixing two items of different prices/strengths:

```
Cheaper : Dearer = (Dearer price - Mean) : (Mean - Cheaper price)
```

**Visual Method:**

```
     Cheaper (C)          Dearer (D)
          \               /
           \             /
            \           /
             Mean (M)
            /         \
           /           \
     (D - M)         (M - C)

Ratio C:D = (D-M) : (M-C)
```

### Replacement Formula

If a container has 'a' litres of liquid and 'b' litres is replaced n times:

```
Final quantity of original liquid = a(1 - b/a)^n
```

## 🎲 10. Permutations & Combinations

### Factorial

```
n! = n × (n-1) × (n-2) × ... × 2 × 1
0! = 1
```

### Permutation (Arrangement matters)

```
ⁿPᵣ = n! / (n-r)!
```

### Combination (Order doesn't matter)

```
ⁿCᵣ = n! / [r! × (n-r)!]
```

### Important Identities

```
ⁿCᵣ = ⁿCₙ₋ᵣ
ⁿC₀ = ⁿCₙ = 1
ⁿC₁ = n
ⁿCᵣ + ⁿCᵣ₋₁ = ⁿ⁺¹Cᵣ
```

### Common Applications

| Scenario                                 | Formula   |
| ---------------------------------------- | --------- |
| Arrange n objects                        | n!        |
| Arrange n with r alike                   | n!/r!     |
| Circular arrangement                     | (n-1)!    |
| Select r from n                          | ⁿCᵣ       |
| Distribute n identical items to r groups | ⁿ⁺ʳ⁻¹Cᵣ₋₁ |

## 🎯 11. Probability

### Basic Formula

```
P(E) = Favorable outcomes / Total outcomes
```

### Properties

```
0 ≤ P(E) ≤ 1
P(E) + P(not E) = 1
P(A or B) = P(A) + P(B) - P(A and B)
P(A and B) = P(A) × P(B)  [if independent]
```

### Common Probabilities

**Single die:**

- P(any specific number) = 1/6
- P(even) = P(odd) = 1/2
- P(prime) = 1/2 (2,3,5)

**Two dice:**

- Total outcomes = 36
- P(sum = 7) = 6/36 = 1/6
- P(sum = 2) = P(sum = 12) = 1/36

**Playing cards:**

- Total = 52, Spades = 13, Hearts = 13, Diamonds = 13, Clubs = 13
- P(Ace) = 4/52 = 1/13
- P(King) = 4/52 = 1/13
- P(Red card) = 26/52 = 1/2

**Coins:**

- 1 coin: P(H) = P(T) = 1/2
- 2 coins: P(2H) = 1/4, P(1H) = 1/2
- 3 coins: P(3H) = 1/8, P(at least 1H) = 7/8

## 📐 12. Geometry & Mensuration

### 2D Shapes

| Shape                | Area              | Perimeter     |
| -------------------- | ----------------- | ------------- |
| Square (side a)      | a²                | 4a            |
| Rectangle (l × b)    | l × b             | 2(l + b)      |
| Circle (radius r)    | πr²               | 2πr           |
| Triangle             | ½ × base × height | a + b + c     |
| Equilateral Triangle | (√3/4)a²          | 3a            |
| Parallelogram        | base × height     | 2(a + b)      |
| Trapezium            | ½(a + b) × h      | a + b + c + d |
| Rhombus              | ½ × d₁ × d₂       | 4a            |

### 3D Shapes

| Shape          | Volume    | Surface Area    |
| -------------- | --------- | --------------- |
| Cube (side a)  | a³        | 6a²             |
| Cuboid (l,b,h) | l × b × h | 2(lb + bh + lh) |
| Cylinder       | πr²h      | 2πr(r + h)      |
| Cone           | ⅓πr²h     | πr(r + l)       |
| Sphere         | (4/3)πr³  | 4πr²            |
| Hemisphere     | (2/3)πr³  | 3πr²            |

### Triangle Properties

**Pythagorean Theorem:**

```
hypotenuse² = base² + height²
```

**Common Pythagorean Triplets:**

- 3, 4, 5
- 5, 12, 13
- 8, 15, 17
- 7, 24, 25

**Area using Heron's formula:**

```
s = (a + b + c)/2
Area = √[s(s-a)(s-b)(s-c)]
```

### Circle Theorems

- Angle in semicircle = 90°
- Angles in same segment are equal
- Angle at center = 2 × Angle at circumference
- Tangent ⊥ Radius at point of contact
