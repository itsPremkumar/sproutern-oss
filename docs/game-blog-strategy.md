training, cognitive games, and exam preparation. Each post will internally link to relevant game

## Internal Linking Strategy

### Every Blog Post Should Include:

1. **3-5 game links** relevant to the topic
2. **1 category hub link** (e.g., /games?category=memory)
3. **1 main games page link** (/games)
4. **2-3 related blog post links**

### Game Page → Blog Links:

- Add "Related Articles" section to game pages
- Link to pillar content for each category

## Content Requirements Per Blog Post

### SEO Essentials

- **Title**: Include primary keyword + numbers/power word
- **Meta Description**: 155-160 chars, include keyword
- **H1**: Unique, includes primary keyword
- **H2s**: 3-5 subheadings with secondary keywords
- **Word Count**: 1500-2500 words minimum
- **Images**: 3-5 with alt text including keywords

### Schema Markup

- Article schema (already implemented)
- FAQ schema (add 3-5 questions per post)
- HowTo schema (for tutorial posts)
- BreadcrumbList schema

### Internal Links

- Minimum 5 internal links per post
- Use keyword-rich anchor text
- Link to games within first 300 words
