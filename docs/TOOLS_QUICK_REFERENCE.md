## 🚀 What Each Tool Does

### 1. Resume Score Checker

- Analyzes resume content
- Provides ATS compatibility score
- Suggests improvements
- Checks for keywords and formatting

### 2. CGPA Converter

- Converts CGPA to percentage
- Supports 4-point, 5-point, 7-point, 10-point scales
- Instant calculation
- University-specific formulas

### 3. Salary Calculator

- CTC to in-hand salary
- Includes PF, Professional Tax, Income Tax
- Monthly and annual breakdown
- Indian tax structure

### 4. Aptitude Mock Test

- 5 quantitative questions
- Instant scoring
- Detailed explanations
- Retake option

### 5. Interview Question Generator

- HR, Technical, Behavioral categories
- 5 questions per category
- Sample answers
- Best practices tips

### 6. Typing Speed Test

- Real-time WPM calculation
- Accuracy tracking
- Performance ratings
- Multiple test texts

### 7. Job Description Enhancer

- Enhances job postings
- 4 job types (Software, Marketing, Sales, Design)
- Adds skills, benefits, formatting
- Copy to clipboard

### 8. Cover Letter Generator

- Creates personalized cover letters
- 3 role types (Software, Marketing, Data)
- Customizable templates
- Professional formatting

### 9. Career Roadmap Generator

- 3 career paths (Full Stack, Data Science, Marketing)
- Beginner & Intermediate levels
- 8-month learning roadmaps
- Skills by phase

### 10. EMI Calculator

- Education loan EMI calculation
- Principal, interest, total breakdown
- Indian currency format
- Formula explanation
