## 2.6 INTERNAL LINKING STRATEGY

### Hub & Spoke Model

#### Hub: /tools (Main Tools Page)

**Spokes:**

- /tools/cgpa-converter
- /tools/resume-score-checker
- /tools/salary-calculator
- /tools/typing-test
- (All 37 tools)

**Internal Links:**

- Each tool links back to /tools
- Each tool links to 3-5 related tools
- Each tool links to relevant blog posts

#### Hub: /blog (Main Blog Page)

**Spokes:**

- /blog/category/interview-prep
- /blog/category/resume-writing
- /blog/category/career-development
- (All 167 posts)

**Internal Links:**

- Each post links to category page
- Each post links to 3-5 related posts
- Each post links to relevant tools

### Contextual Linking Rules

1. **Anchor Text Variation**

```
❌ Bad: "click here" "read more" "this page"
✅ Good: "CGPA calculator" "interview preparation guide" "resume templates"
```

2. **Link Placement**

```
✅ Within first 100 words
✅ In content body (contextual)
✅ In "Related Resources" section
✅ In author bio
```

3. **Link Density**

```
✅ 2-5 internal links per 500 words
❌ Avoid over-linking (>10 links per 500 words)
```

## 2.7 IMAGE SEO

### Current Issues

🟡 Some images missing alt text 🟡 Generic filenames (image1.jpg) 🟡 Missing image captions

### Optimization Checklist

#### Alt Text Formula

```
[What it is] + [Context] + [Keyword if natural]
```

**Examples:**

```html
<!-- Bad -->
<img
  src="image1.jpg"
  alt="image"
/>

<!-- Good -->
<img
  src="cgpa-calculator-interface.jpg"
  alt="CGPA to percentage calculator interface showing Anna University conversion"
/>

<!-- Bad -->
<img
  src="photo.jpg"
  alt="resume"
/>

<!-- Good -->
<img
  src="ats-friendly-resume-template.jpg"
  alt="ATS-friendly resume template for software engineers with clean formatting"
/>
```

#### Image Filename Optimization

```
❌ IMG_1234.jpg
❌ screenshot.png
❌ photo-1.jpg

✅ cgpa-calculator-anna-university.jpg
✅ ats-resume-template-software-engineer.png
✅ interview-preparation-checklist-2026.jpg
```

#### Image Structured Data

```json
{
  "@type": "ImageObject",
  "contentUrl": "https://sproutern.dpdns.org/images/cgpa-calculator.jpg",
  "description": "CGPA to percentage calculator interface",
  "name": "CGPA Calculator",
  "author": {
    "@type": "Organization",
    "name": "Sproutern"
  }
}
```

### Content Freshness Strategy

#### Update Frequency

- **Homepage:** Weekly
- **Tools:** Monthly (add new features)
- **Blog Posts:** Quarterly (update stats, examples)
- **Guides:** Bi-annually (major updates)

#### Freshness Signals

```html

  name="last-modified"
```
