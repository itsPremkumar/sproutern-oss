# GO_LIVE — Sproutern Launch Sequence

**Goal:** convert the fixed indexing into the first 500–1,000 real visitors.
**Rule of the game:** one platform per day. Engagement velocity (replies in the
first 24h) decides whether launch sites promote you. Do not burst-post.

---

## Pre-flight (do once, ~30 min)

- [ ] GitHub social preview image: Repo → Settings → General → Social preview
      (upload a 1280×640 banner: logo + "200+ free career tools" + domain)
- [ ] Pin the repo on your GitHub profile (Profile → Customize your pins)
- [ ] Vercel Analytics: confirm this week's baseline (~28 visitors) so lift is measurable
- [ ] GSC: request indexing for `/`, `/tools`, `/games`, `/interview-experiences/tcs`
      (URL Inspection → Request Indexing)
- [ ] Prepare 2–3 screenshot images for PH / Reddit: converter tool, an interview
      experience page, the games grid

## Launch week

| Day | Platform | Action |
|-----|----------|--------|
| Tue | Product Hunt | Post at ~12:30 PT from LAUNCH_POSTS.md §1. First comment immediately. Reply to all comments same-day. |
| Tue | Hacker News | Show HN post §2 at ~17:00 PT (US morning traffic, after PH settles). Monitor newest page; if it stalls, don't repost — engage elsewhere. |
| Wed | Reddit | r/Btechtards §3 (9–11am IST). Answer every comment as the builder. Then r/developersIndia variant next week, not same day. |
| Thu | X thread | Post §4, pin it. Quote-tweet the PH/HN links. |
| Fri | dev.to | Publish §5 article with canonical URL → your blog. Cross-link from X. |

## Weeks 2–3 (sustain)

- [ ] r/developersIndia + r/SideProject variants
- [ ] LinkedIn post (§6)
- [ ] Answer 5+ live questions on Reddit/Quora per week using your radar digests
      (cron delivers drafted answers daily — edit to sound like you, then paste)
- [ ] Submit to directories: AlternativeTo, SaaSHub, free-for.dev list PR,
      awesome-india lists, Hacktoberfest project boards (it's MIT)
- [ ] Ping 2–3 newsletter curators (e.g. JavaScript Weekly "project" form,
      India-tech newsletters) with a 3-line pitch

## Metrics that decide success (check weekly digest)

- Vercel Analytics: visitors/day trend vs 1.3 baseline
- GSC: impressions (leading), clicks (lagging), indexed-pages count rising
- GitHub: stars, issue engagement, any first external PR

## Honest expectations

- Launch spike: 300–800 visitors over launch week if even one platform picks up
- Without a pick-up: 50–150 from direct sharing alone — still 10× current
- Organic compounding starts mattering at month 2–3; programmatic pages are the flywheel
